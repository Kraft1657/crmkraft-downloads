# CRM Kraft Desktop v0.3.1 — versão experimental

**Plataforma:** Windows 10/11, 64 bits.

Esta versão utiliza Electron para abrir o CRM Kraft online em uma janela independente do navegador. O acesso depende de conexão com a internet e de uma conta autorizada no sistema.

## Funcionalidades previstas nesta versão

- Janela própria para utilizar Comercial e Engenharia, respeitando as permissões existentes.
- Opções de instalador Windows e executável portátil.
- Bandeja do Windows e opção de inicialização automática.
- Integração experimental com notificações do Windows.

## Arquivos da distribuição oficial

- **Instalador:** `CRM-Kraft-Desktop-Setup-0.3.1-x64.exe`.
- **Portátil:** `CRM-Kraft-Desktop-Portable-0.3.1-x64.exe`.
- **Checksums:** `SHA256SUMS.txt`.

Os valores SHA-256 correspondem à compilação concluída pelo GitHub Actions para a versão 0.3.1. Outros executáveis com o mesmo nome ou número de versão podem ter hashes diferentes.

## Atenção

- A versão **não possui assinatura digital**.
- É necessário testar o comportamento em computadores Windows antes de distribuir amplamente.
- O instalador não contém credenciais de usuários nem acesso administrativo ao CRM.
- Não publique neste repositório nenhum arquivo de configuração, token, segredo, código-fonte privado ou exportação de dados.

O CRM Kraft continua hospedado na infraestrutura online atual.
